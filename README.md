# 🎁 Подарунок за QR-кодом

Сайт для новорічних подарунків: адмін завантажує фото або відео, отримує PDF із QR-кодом, а людина сканує QR і бачить тільки свій файл на весь екран.

- Сторінка подарунка: `index.html?g=<код>`
- Адмінка: `admin.html`
- Дані і файли зберігаються в Supabase (налаштування — `config.js`).
